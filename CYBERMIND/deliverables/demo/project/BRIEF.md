# CYBERMIND live demo

Audience: SIH26153 judges. Show the user's real application, with actual upload, forecasting, simulations, bounded local sandbox probes and encrypted reporting.

Hard limit: 110 seconds. 1920×1080, 30 fps. Only `cybermind new 2.wav` supplies narration; no generated speech or music. Narration must remain continuous and can be slowed slightly if the limit permits. Title page Frame1, CYBERMIND page Frame2, uploaded architecture JPG at the ending. All application segments are live recordings, not screenshot slides or reconstructed UI.

Capture full-screen CYBERMIND desktop. Include actual File Explorer PCAP selection, real results and in-app interactions. Show Command Centre, host graph, Live Monitor, Flagged Flows, Threat Forecast, Attack Graph, Parallel Futures, Strix Lab's built-in loopback probe → analyst-approved defence → identical probe blocked, local validator's HTTP codes and hashes, offline assistant, report encryption/decryption and benchmark. Reports may briefly show the encrypted JSON in Notepad; keep report keys and unrelated private files off camera.

Short subtitles cover features without narration. Local sandbox checks must not be represented as autonomous external Strix execution, model retraining or accuracy verification. Unconfigured external controls remain separate and need not be expanded during recording. No fabricated results or staged success indicators.

Movement: restrained smooth push-ins, ≤108%; no shaking or continuous floating. Cut only dead time, preserve live action and real results; smooth short overlapping dissolves between edited scenes. Strix probe/defence/re-test is real-time footage.

Output: local editable Hyperframes project, preview, final MP4 after preview approval.

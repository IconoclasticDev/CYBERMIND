# CYBERMIND app package

This archive contains the current FastAPI backend, React source and built UI, local examples, project documents, and the model checkpoints. The default checkpoint is `models/best.pt`, selected at epoch 21; `models/best_last.pt` is epoch 25 and is included for reference only. The checkpoint and UI are loaded by the app at startup.

The bundled UI is already built; Node.js is not needed to view it. This ZIP does not embed Python/PyTorch or create a standalone EXE. On a machine with compatible Python packages installed, run `python -m uvicorn app.main:app --host 127.0.0.1 --port 50068` from the extracted CYBERMIND folder, then open http://127.0.0.1:50068/. To set up dependencies, install `requirements.txt` and `requirements-app.txt` in a virtual environment. The model loads on startup; verify `/api/model` reports `checkpoint_name` as `best.pt` and `available` as true.

For the reviewed four-step inference horizon, set `CYBERMIND_ROLLOUT_STEPS=4` before starting the server. The package's Windows and Unix launch scripts set this automatically. All inference runs locally. Strix controlled validation needs its separate runtime and is not made available merely by this ZIP.

This merged UI retains the original archive's pages and navigation and adds two local features: a floating read-only NLP chatbot and encrypted incident-brief export/decryption in Reports. The chatbot answers from telemetry and model state in the current app session; it does not send questions to an external service or execute actions. A new report export downloads AES-256-GCM JSON and shows a separate one-time key. Send the key separately from the JSON. The recipient can decrypt in the Reports page or use the standalone offline tool at `tools/incident_decrypter/index.html` (also served at `/incident-decrypter` by the app). The standalone tool can download a readable JSON copy. Legacy passphrase-encrypted reports are supported too. The downloaded readable copy is unencrypted.

The previous real raw-file demo capture is included at `examples/demo_real/ctu_iot23_capture_9_1_only5000.pcap` with its SHA-256 and source in `examples/demo_real/provenance.json`. It tests PCAP ingestion; it is not a measured accuracy result on the CTU dataset. The original archive's CIC-IDS2018 flow CSV samples remain available.

For Docker deployment, `docker compose up --build -d` serves the FastAPI/React app on `http://127.0.0.1:8000/` and the separate decrypter on `http://127.0.0.1:8001/`. The app container includes the Docker CLI and mounts the host Docker socket, which gives it control of the host daemon. The built-in local validation check runs after a case is loaded and freezes a fresh forecast; both bundled cases passed in the container. Strix controlled validation also needs the Strix CLI, a live registered sandbox target, and an LLM provider. Docker access alone does not enable that separate scan.

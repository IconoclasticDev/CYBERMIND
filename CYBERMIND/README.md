# CYBERMIND project files

Use **START_WINDOWS.cmd** on Windows or `sh START_LINUX.sh` on Linux x86-64. They select the current release, verify it and prepare it automatically. Docker must be installed.

The complete application guide is in the repository-root [README](../README.md). Current release details are in [releases/README.md](releases/README.md), final video in [deliverables/demo](deliverables/demo), and application source in `CYBERMIND_REAL/integrations/cybermind_deep_merged_2026-09-29/`.

Historical research outputs with identical contents were consolidated. `deliverables/REPOSITORY_DUPLICATE_AUDIT.json` maps removed copies to the originals. The independent training and Docker source contexts retain the files each needs for imports and builds.

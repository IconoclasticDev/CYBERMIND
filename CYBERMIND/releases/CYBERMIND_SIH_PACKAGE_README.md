# CYBERMIND SIH Submission Package

Download `CYBERMIND_SIH_SUBMISSION_2026-09-26.zip`, verify it against the adjacent manifest, and extract it. The package contains:

- the complete current source, configurations, scripts and tests;
- the selected epoch-21 checkpoint;
- final grouped validation, test and baseline-suite results;
- the two-page architecture document and implementation plans;
- PowerPoint-ready PNG/SVG comparison assets; and
- the Streamlit offline analyst console.

Start with `CYBERMIND_REAL/README.md`. The default analyst checkpoint is `CYBERMIND_REAL/checkpoints/final_grouped/best.pt`.

Raw, intermediate and processed datasets are intentionally excluded because they exceed GitHub limits and have separate provenance. Historical checkpoints, epoch snapshots, credentials, caches and live runtime status files are also excluded. The internal `PACKAGE_MANIFEST.json` records every included file and SHA-256 hash.
